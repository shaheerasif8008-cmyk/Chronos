Manus-like Computer Runtime Model

Proposed Chronos target: three environments with one task router and shared replay/artifact model.

Temporary Sandbox

Default per-task workspace for one-off code, files, documents, analysis, and artifact creation. Ephemeral but replayable.

Cloud Computer

Persistent workspace with plan, state, services, ports, process history, saved files, and attached cloud browser.

My Computer

Local bridge with authorized folder grants, explicit command/app approvals, revoke controls, and local event audit.

Runtime Routing

Chat / Task

User asks Chronos to build, research, run, host, automate, or edit local files.

→

Environment Router

Chooses sandbox, persistent cloud computer, local bridge, and cloud browser based on task needs and permissions.

Services

Ports, URLs, processes.

Files

Workspace and exports.

Browser

Sessions, takeover, downloads.

Replay

Durable timeline across refresh.
